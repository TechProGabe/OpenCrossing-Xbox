This one started with a crash report and kind of snowballed. It fixes the gyroid crash, makes the game run better, and finally gives the Game Boy Advance and e-Reader parts of the game something to do on a console that can't plug either of them in.

Download `OpenCrossing-Xbox-v1.2.zip` below. Coming from v1 or v1.1? Copy the new `default.xbe` and `default.tbn` over the old ones. Your saves and settings carry over. First time? The install steps are in the [README](https://github.com/TechProGabe/OpenCrossing-Xbox#download), and you still need your own Animal Crossing (USA, GAFE01) disc image.

## Runs better

- **Built with LTO and PGO.** The game is now compiled as one big program instead of thousands of separate pieces (link-time optimization), and tuned using real play sessions so the code you actually hit most runs fastest (profile-guided optimization). Same game, tighter code, and about half a megabyte more free memory on a stock 64 MB console.
- **No more freeze when opening menus.** Opening the pockets or any other menu used to hang for close to half a second at 720p while the game grabbed the screen behind it. Now it's under a tenth of a second. Texture loading got the same treatment, so everything that loads textures benefits a little.

## Disc validation

The first time you boot a disc image, the game checks it. Every file the game reads is verified against a known good copy of the USA disc, one by one, and you watch the stamps land on a letter while it works. It takes about a second. Once an image passes, the game remembers it, and later boots only do a quick check.

If something's off, it tells you plainly instead of crashing an hour into your session:

- The wrong release (PAL, Australian, Japanese or USA Rev 1) is named and turned away.
- A modded or NKit image, or one trimmed too far, is caught before the game starts.
- A damaged file gets crossed out, and you can play anyway (A) or quit (B).
- A trimmed, scrubbed or rebuilt image is fine. It checks what's in the files, not where they sit on the disc.

Hold Y and both triggers while the game starts to run the full check again.

## A new boot screen

A letter from TechProGabe on ruled paper greets you on first boot, with a stamp for each file as it checks out. After that, you get a "Welcome back to town!" note and a loading bar that always fills all the way before the game takes over. The screens cost next to nothing, so they don't slow loading down.

## No GBA? No problem

An Xbox can't connect a Game Boy Advance, an e-Reader or a GameCube memory card, so the parts of the game that wanted one got reworked. We won't spoil the details. Here's where to look:

- **The island.** You don't need a Game Boy Advance to get there anymore. Go have a chat with Kapp'n.
- **The e-Reader.** Try the machine at the post office.
- **The train.** Ask the Porter about visiting another town.
- **Nookington's.** Tom Nook no longer needs a visitor from another town to finish growing his store. The Options toggle for this is gone because it's always on.
- **No dead-end menus.** Game Boy Advance options are gone from the menus. Everything else works like it always did.

If someone gives you something along the way, save your game to keep it.

## Fixed

- Storing an item with a gyroid and closing the menu no longer crashes the game. The catalog had the same bug and got the same fix.
- Flipping through the address book while writing a letter could freeze the menu. The music kept playing but nothing responded to the controller. The page turn now finishes every time ([#4](https://github.com/TechProGabe/OpenCrossing-Xbox/issues/4)).
