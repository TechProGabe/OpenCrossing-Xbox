A small fix release on top of [v1](https://github.com/TechProGabe/OpenCrossing-Xbox/releases/tag/v1).

Download `OpenCrossing-Xbox-v1.1.zip` below and copy the new `default.xbe` and `default.tbn` over the old ones. Your saves and settings carry over.

## Fixed

- **Crash on consoles with an upgraded CPU** ([#2](https://github.com/TechProGabe/OpenCrossing-Xbox/issues/2), [#3](https://github.com/TechProGabe/OpenCrossing-Xbox/issues/3)): the game crashed after Rover's train in a new town, or on START at the title. Some custom BIOSes on upgraded consoles change a game's code in memory to slow down games made for the stock 733 MHz CPU, and in OpenCrossing that change hit two bytes it shouldn't have. The game now checks its code against `default.xbe` when it starts and puts back anything that was changed. Thanks to everyone who sent logs and tested.

Everything else is the same as v1. The known issues are listed in [docs/known-issues.md](https://github.com/TechProGabe/OpenCrossing-Xbox/blob/main/docs/known-issues.md). `ac_xbox.map` is only for reading crash logs.
